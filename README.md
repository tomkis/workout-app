# Workout App

A simple workout tracking PWA for hypertrophy training.

## Stack

- **React + TypeScript** — UI and type safety
- **Vite** — build tool and dev server
- **vite-plugin-pwa** — service worker and offline support

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Pushes to `main` automatically build and deploy to GitHub Pages via GitHub Actions.
